# Web 工作台 v2

## 日常使用

双击根目录 `start_web.bat`。服务就绪后自动打开 http://127.0.0.1:8000，默认进入下载整理。无需先运行扫描，也无需保持启动窗口打开。

1. 按大小分组并重命名：把下载根目录的视频按大小归类。已归类的历史视频可在“目录位置与辅助操作”中单独命名。
2. 与视频库比对：仅将下载区与视频库比较。若有未分类视频，确认框会明确说明先分组并重命名再比对；重新比对会替换当前审阅列表，取消不会启动任何操作。
3. 进入相似审阅：同步观看两个视频并作出决定。每个视频顶部标明“下载区”或“视频库”，文件名下显示目录。红色“删除此视频”按钮只删除所在侧的视频并送入 Windows 回收站；“均保留并忽略此组”会保存忽略决定，以后不再提示此组。键盘仅支持左右切组，不再用 K 保存忽略决定。恢复回收站文件后可重新扫描以更新相似结果。
4. 移动到视频库：将分类目录中的视频移动到最终视频库并写入缓存。尚有相似组时会明确提示，可返回审阅，也可确认跳过审阅。

## 运行状态与失败处理

- 分类、比对、移动和缓存写操作都有后台任务 ID，页面上方显示当前阶段、真实的阶段进度或处理提示。
- 可以切换页面、刷新页面或关闭浏览器。重新打开后会读取仍在运行的任务。
- 一个任务运行期间，其余文件写操作被暂时禁用；其他标签页发来的冲突操作也会被后端拒绝。
- 网络请求失败时，不会自动重复提交文件操作。页面自动尝试重连，请先核对任务记录再重新发起操作。
- “部分完成”表示一些文件已经处理成功，另一些失败。任务详情保留完整明细，可导出 JSON，没有前 20 条截断。
- 迁移成功但缓存失败时，视频已经在最终视频库。可在维护页“计算缺失特征”，只补建失效或缺失的特征，不再次移动文件。
- 关闭后端会中断任务。重启后会显示中断状态；不会自动恢复计算或自动重复文件操作。
- 视频格式或编码不被浏览器支持时，可通过“在文件夹中显示”打开原文件确认。

首页最近操作中的待审阅数量跟随当前列表更新；扫描完成时的历史数量仅保留在任务详情中。

## 低频维护

“维护与记录”保留最近 20 次后台任务。全库扫描和缓存清理放在这里；日常使用下载区增量比对即可。

缓存维护区域自动显示无用缓存数量、可释放空间和检查时间，可手动刷新；删除后自动重新检查。检查不生成任务记录，也不删除文件。无用缓存删除仅删除缓存文件，不删除视频。缓存数量不代表有效覆盖率，缺失特征可单独计算。

任务记录右上角可清空全部历史记录，确认后持久化清空，同时更新首页最近操作。运行任务期间禁用清空；清空不影响视频、缓存和当前审阅结果。

## 部署和验证

前端仍由 Python 服务提供，无需 Node 构建或安装新 Python 依赖。ArtPlayer 5.4.0 已固定并随项目提供，MIT 许可证见 `utils/video_similarity/assets/ARTPLAYER-LICENSE`。

启动脚本将日志写入 `output/web-launcher.stdout.log` 和 `output/web-launcher.stderr.log`。若端口被旧服务占用，关闭旧服务后再启动。调试时可直接运行：

```powershell
python scripts/run_similarity.py --server-only --no-browser
```

测试代码仅在本地保留，不随仓库发布。以下命令适用于已有本地 `tests/` 目录的工作环境：

```powershell
python -m unittest discover -s tests -v
# 前端回归测试（需要 Node.js，仅测试使用）
Get-ChildItem tests -Filter *.cjs | ForEach-Object {
    node $_.FullName
    if ($LASTEXITCODE -ne 0) { throw "前端测试失败：$($_.Name)" }
}
```

测试使用临时目录、独立配置和生成的小视频，覆盖分类、命名幂等性、增量扫描、迁移和缓存、缓存失败的部分完成、任务互斥与重启恢复、审阅持久化失败、移除失败、清空历史的持久化与互斥、缓存统计及清理保护，以及视频 Range 请求。前端测试覆盖参数比较、图表悬停、删除对象、来源标签、当前待审阅数量、确认取消和维护操作。不会处理真实下载目录或视频库。回收站接口在自动化集成测试中被替换为临时目录内的可恢复移动。

## 参数审阅与分布图

综合相似度与分项分数置于播放器上方；两侧时长、分辨率、文件大小独立显示，高亮较大一侧并标注差异。数值更大只代表参数差异，不能直接认定画质更好。报告保存精确秒数和字节数，避免按四舍五入后的文本比较。

视频库使用本地 Chart.js 4.5.1，支持数量／容量切换、悬停数值、按 2 倍区间分桶的大小直方图及累计数量占比。下方可展开完整数据表；加载失败保留已有数据并给出提示。库文件和 MIT 许可证位于 assets，无在线 CDN 请求。
